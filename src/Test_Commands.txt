/*
IMPORTANT USAGE NOTES:

1. Always enable motors before moving them
2. Check if motors are running before starting new movements
3. Use forceStop() for emergency stops
4. Monitor serial output for motor status updates
5. Remember that enable pins are ACTIVE LOW
6. Button is configured as ACTIVE HIGH with pulldown
7. Motors use FastAccelStepper library - movements are non-blocking
8. Sequence state machine runs automatically when button is pressed
9. OTA updates are handled automatically in main loop
10. Serial baud rate is 115200

SAFETY REMINDERS:
- Always disable motors when not in use
- Use emergency stop commands if needed
- Check motor positions before large movements
- Monitor for overheating during continuous operation
- Ensure adequate power supply for dual motor operation

TROUBLESHOOTING:
- If motors don't move, check enable pins
- If movements are jerky, adjust acceleration values
- If motors miss steps, reduce speed or increase acceleration
- If button doesn't respond, check debounce timing
- If OTA fails, check WiFi connection and IP address
*/
